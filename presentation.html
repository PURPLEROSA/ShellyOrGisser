01

מסך זה לא תמונה — זה טיעון

2:00–5:30

הרעיון המרכזי

מסך UI הוא טיעון ויזואלי

  • מישהו החליט מה תראו קודם, מה שני, ומה אחרון
  • מישהו החליט איפה לשים חיכוך ואיפה להסיר אותו
  • מישהו החליט מה מרגיש גדול ומה מרגיש קטן
מה שמעניין במסך זה לא מה כתוב עליו — אלא איך הוא בנוי.
מבנה > תוכן.
חשיבה ויזואלית

5 שכבות שחושפות לוגיקה

1
צפיפות ויזואלית
דליל / מאוזן / צפוף — מה המותג מרגיש לגבי פשטות?
2
תפקידי צבע
לא "איזה צבעים" — אלא מה הצבע של הרקע, הפעולה, והאקסנט עושים
3
לוגיקת היררכיה
מה תופס את העין קודם? שני? שלישי? → סדר עדיפויות
4
לוגיקת CTA
איפה מעודדים פעולה? כמה בחוזקה? לוחש או צועק?
5
התנהגות רכיבים
כרטיסים, טפסים, ניווט — לא רק *מה* יש, אלא *איך* זה מתנהג

מתובנות לכיוון עיצובי | 10:00–14:00

תרגום קריאטיבי

3 מוצרים שמיד אפשר להשתמש בהם

A
בריף קריאטיבי קצר
פסקה אחת שמכוונת צוות שלם. לא 20 עמודים — אמירה חדה.
B
כללי UI מדידים
ריווח, היררכיה, דגש, צפיפות. מספרים — לא תחושות. שמירה כ-JSON.
C
פרומפטים מוכנים
Copy-paste ישר ל-Google Stitch, Figma Make, או כל כלי prompt-based.
A — בריף קריאטיבי

פסקה אחת. כיוון שלם.

“הכיוון הוא מינימליזם פונקציונלי — לא מינימליזם "יפה" אלא מינימליזם שפועל. כל אלמנט על המסך חייב להצדיק את קיומו. רווח לבן הוא לא ריק — הוא חלק מההיררכיה. CTA יחיד בכל מסך, בולט אבל לא צועק.”
זה לא סתם טקסט — זו מפת דרכים לצוות עיצוב
B — כללי UI

כללים מדידים, לא הנחיות מעורפלות

ריווח
group-spacing: 24px
card-padding: 16px
section-gap: 48px
היררכיה
type-levels: 3 max
scale-ratio: 1.5
weight-range: [400, 700]
דגש
primary-cta-per-viewport: 1
accent-color-use: actions-only
emphasis-method: size + weight
צפיפות
max-elements-above-fold: 7
visual-density: sparse
whitespace-ratio: 0.4
JSON Design Tokens שיתוף צוותי

פרומפט גנרי מול פרומפט מבוסס-ניתוח

❌ גנרי

✅ מבוסס-ניתוח
SaaS analytics dashboard.
Sparse density. Max 5 data cards.
Single metric + micro-chart per card.
CTA: 1 primary (export),
2 secondary (filter, date).
Left sidebar, icons only.
Gray-50 bg, blue-500 data,

3 type levels. 24px group spacing.
הראשון נותן dashboard. השני נותן את ה-dashboard הנכון.

Google Stitch — מפרומפט ל-UI

מה זה?
  • Google רכשה את Galileo AI (I/O 2025)
  • כותבים prompt → מקבלים מסכים + HTML/CSS
  • ייצוא ל-Figma בלחיצה אחת
  • Gemini 3 integration (דצמבר 2025)
למה זה חשוב?
  • חינמי לחלוטין
  • פרומפט מבוסס-ניתוח = תוצאה 10x טובה יותר
  • Standard Mode (מהיר) + Experimental (איכותי)
  • מושלם לקונספטים ראשוניים
כלי

Figma Make — ה-design system שלכם הוא הפרומפט

  • שולף את הכפתורים, הכרטיסים והלייאאוטים שהצוות כבר משתמש בהם
  • מייצר פרוטוטייפים on-brand מהשנייה הראשונה
  • משתמש ב-Claude 3.7 מתחת למכסה המנוע
  • MCP Server — סורק codebase ומפיק קבצי כללים מובנים
ניתוח AI + מערכת עיצוב קיימת = פרומפט שהוא כבר חצי-מוצר

שלוש פעולות שתעשו מחר בבוקר

1
תצלמו 5 מסכים
אפליקציות שמרגישות "נכון". תשאלו את AI את 4 השאלות: למה? ממה? איפה פשוט? איפה חיכוך?
2
תייצרו פרומפט מהניתוח
תכניסו ל-Google Stitch (חינם) או Figma Make. תשוו לפרומפט גנרי. תראו את ההבדל.
3
תבנו קובץ כללים
ריווח, היררכיה, דגש, צפיפות → JSON או Markdown → שתפו עם הצוות. זה הצעד הראשון ל-design system שמדבר AI.

AI לא צריך לעצב בשבילכם.
הוא צריך לעזור לכם לראות.

מה להפעיל ב-Google Cloud
  1. צרי פרויקט ב-console.cloud.google.com והפעילי חיוב.
  2. הפעילי: Maps JavaScript API, Places API, Geocoding API, Street View Static API.
  3. Credentials → Create API Key.
  4. הגבילי את המפתח ל-HTTP referrers של הדומיין שלך בלבד.
בלי מפתח: הגלריה, לוח ההפקה, התמונות והפרומפטים עובדים במלואם. המפה ו-Street View לא.

Character Lock · האוואטר שלך

התיאור הזה נכנס לכל פרומפט שהמעבדה מייצרת — ככה הדמות נשארת אותה דמות בכל המיקומים.

תמונות הפנים שלך

הרפרנסים שאת מעלה לכלי היצירה כדי לנעול את הזהות. 3–8 תמונות: חזית, פרופיל, שלושת-רבעי, תאורות שונות, בלי משקפיים ובלי כובע.

לחיצה על תמונה מסמנת אותה כרפרנס הראשי. התמונות נשמרות רק במכשיר הזה.
התקנה בטלפון

מתקינים פעם אחת והמעבדה נפתחת כמו אפליקציה — מסך מלא, בלי סרגל דפדפן, ונטענת גם בלי קליטה.

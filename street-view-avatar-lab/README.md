# STREET VIEW AVATAR LAB

לוח הפקה נייד למיקומי צילום — נבנה לטיול בארה״ב.
עובד לגמרי בדפדפן: אין שרת, אין חשבון, אין העלאה לשום מקום.

## הפעלה

פותחים את `index.html` — מקומית או דרך GitHub Pages.

בכניסה הראשונה מדביקים **Google Maps API key**, או נכנסים בלי מפתח (מצב לוח הפקה בלבד).
המפתח נשמר ב-`localStorage` של הדפדפן וניגש רק לגוגל.

### מה להפעיל ב-Google Cloud
בפרויקט עם חיוב פעיל: `Maps JavaScript API`, `Places API`, `Geocoding API`, `Street View Static API`.
מומלץ להגביל את המפתח ל-HTTP referrers של הדומיין בלבד.

## מה יש בפנים

| מסך | מה הוא עושה |
|---|---|
| **מפה** | חיפוש מקום בארה״ב, לחיצה על המפה, או GPS "אני פה עכשיו". פאנורמת Street View חיה — מסובבים לזווית הרצויה והיא נשמרת כקאדר (heading / pitch / fov). |
| **גלריה** | כל המיקומים ככרטיסים, עם סינון לפי סטטוס, תגית וטקסט חופשי, ומיון כולל "הכי קרוב אלי". |
| **לוח הפקה** | חמש עמודות: רעיון → סקאוט → צולם → בעריכה → פורסם. גרירה בדסקטופ, חצים בנייד. |
| **הגדרות** | Character Lock, מפתח API, גיבוי ושחזור. |

## Character Lock

התיאור שממלאים בהגדרות (שם, מראה, סטיילינג, חתימה קולנועית) נכנס לכל פרומפט שהמעבדה מייצרת —
כך אותה דמות חוזרת בכל המיקומים. שינוי שם משתקף מיד בכל הפרומפטים.

## אור

שעות הזריחה, השקיעה, ה-Golden Hour וה-Blue Hour מחושבות מקומית (NOAA), בלי רשת,
ומוצגות **בשעון של המיקום עצמו** — לא של המכשיר. מאפשר לתכנן צילום בניו-מקסיקו בזמן שיושבים בקליפורניה.
אזור הזמן נגזר מהקואורדינטות (כולל אריזונה בלי שעון קיץ).

## התקנה בטלפון

בטלפון פותחים את הכתובת ומתקינים:

- **אייפון (Safari):** כפתור השיתוף ← "הוספה למסך הבית"
- **אנדרואיד (Chrome):** תפריט שלוש הנקודות ← "התקנת אפליקציה", או הכפתור בהגדרות

אחרי ההתקנה זה נפתח כמו אפליקציה — מסך מלא, בלי סרגל דפדפן, ונטען גם בלי קליטה.

## סנכרון בין מכשירים

בהגדרות ← "סנכרון בין מכשירים" מזינים מייל ומקבלים קישור כניסה.
מתחברים פעם אחת בטלפון ופעם אחת במחשב, ומאותו רגע המיקומים, ההערות, הפרומפטים
ותמונות הרפרנס זהים בשני המקומות.

הסנכרון עובד מול Supabase (`svlab_locations`, `svlab_profile`, ובאקט `svlab-shots`).
כל השורות מוגנות ב-RLS לפי `auth.uid()` — המפתח הציבורי שבדף לא מאפשר לקרוא שום נתון בלי התחברות.

המיזוג הוא last-write-wins לפי חותמת הזמן של כל מיקום בנפרד, כך ששני מכשירים
שערכו מיקומים שונים לא דורסים זה את זה. מחיקה נרשמת כ-tombstone ומתפשטת למכשיר השני.

### הגדרה חד-פעמית

אם קישור הכניסה מחזיר שגיאה — ב-Supabase תחת **Authentication → URL Configuration → Redirect URLs**
צריך להוסיף את כתובת הדף. הכתובת המדויקת מוצגת בהודעה שמופיעה אחרי שליחת הקישור.

## איפה נשמרים הנתונים

- מיקומים, תגיות, הערות, פרומפטים והגדרות — `localStorage`
- תמונות רפרנס — `IndexedDB` (נדחסות ל-1500px / JPEG לפני שמירה)

בלי סנכרון, הכל יושב רק בדפדפן — וניקוי היסטוריית הגלישה מוחק את הכל.
גם עם סנכרון, בהגדרות יש שלושה ייצואים: מלא (כולל תמונות), קל (בלי תמונות), ו-Markdown של כל הפרומפטים.
כדאי לייצא כל כמה ימים בטיול.

המפה ותמונות ה-Street View דורשות חיבור.
